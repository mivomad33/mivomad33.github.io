# 프로젝트 시드 문서

- 대상: 채용 담당자, 사업 파트너나 고객, 개발자 독자, 일반 커뮤니티 등 누구나 볼 수 있다. 블로그 글을 검색해서 들어오는 방문자도 있다.
- 문제: 내 프로필, 포트폴리오, 블로그를 관리·운영할 사이트가 없어서 활동한 결과물이 남지 않는다.
- 목표: 프로필, 포트폴리오, 블로그를 담은 웹사이트를 개발한다.
- 이유: 활동한 결과물을 남겨서 언제든 활용할 수 있게 하기 위해서다.
- 성공의 모습:
  - 프로필, 포트폴리오, 블로그가 방문자에게 잘 전달된다.
  - 블로그 글은 md 파일을 추가하고 push하면 자동으로 배포된다.
  - 프로필과 포트폴리오도 데이터 파일만 고치면 사이트에 반영된다.
- 현재 상황: 나는 8년 차 웹 개발자이고, Claude Code를 활용해 개발한다. 온라인 활동명은 mivomad33이다.
- 방향:
  - 기술
    - 정적 사이트로 개발해 GitHub Pages로 호스팅하고, 이미 확보한 mivomad33.dev 도메인을 연결한다.
    - 블로그는 웹에서 입력하지 않고, md 파일을 빌드해 정적 콘텐츠로 만들어 배포한다.
    - 검색으로 들어오는 방문자가 있으므로 검색 노출(SEO)을 고려한다.
  - 콘텐츠
    - 프로필 페이지에 포트폴리오를 함께 넣는다.
    - 블로그에는 개발, 사업 관련 활동 기록을 게시한다.
  - 디자인: 미니멀한 디자인을 원한다.
- 미정 사항:
  - 프레임워크: 여러 프레임워크(Astro, Next.js 등)와 구현 방식을 검토해, AI 주도 개발을 전제로 가장 적합한 것을 정한다.
  - 사이트 언어: 한국어만 사용한다.
