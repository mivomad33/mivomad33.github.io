# 변경 3: 소개 페이지에 프로필 이미지

- 상태: 완료(2026-10-21). 하위 단계 1(시안)·2(구현)를 마친 뒤 변경 전체가 사용자 검토를 통과해 main에 squash merge했다.
- 브랜치: `change/profile-image`

## 배경

- 지금 소개 페이지는 활동명, 한 줄 소개, 이메일, 링크만 있는 글자 위주 화면이다.
- 사용자가 직접 만든 픽셀 아트 캐릭터(후광과 날개가 있는 인물, 512×512 SVG)를 소개 페이지에 보여 주자고 제안했다(2026-10-21). 사이트의 터미널 느낌(`~/`, `# `, 고정폭 글꼴)과 레트로 픽셀 아트가 어울리고, 색이 차분해 다른 요소보다 튀지 않는다.

## 요구사항

### 해야 하는 것

- 소개 페이지(한국어·영어)에 프로필 이미지를 보여 준다.
- 이미지 둘레에 사이트 배경과 다른 색의 네모가 보이지 않는다.
- 픽셀 그림의 칸이 고르게(같은 폭으로) 선명하게 보인다.
- 데스크톱과 모바일(375px)에서 가로 스크롤 없이 보인다.

### 하지 않는 것

- 파비콘, OG 이미지, 헤더 등 다른 곳에는 넣지 않는다. 같은 캐릭터로 바꾸면 사이트 정체성이 통일되지만, 이번 변경의 범위를 소개 페이지로 좁힌다(필요하면 따로 변경을 만든다).
- 다크 모드용 이미지는 만들지 않는다(사이트에 다크 모드가 없다).

## 설계

### 이미지

- 원본: 사용자가 만든 `mivomad33_profile.svg`(512×512, 24px 칸 단위, `shape-rendering="crispEdges"`). 저장소 밖에 있다.
- 원본에서 크림색 배경 사각형(`#FCF6EC`)만 뺀 투명 버전을 쓴다. 사이트 배경(`#fcfcfc`)과 색이 달라 그대로 두면 이미지 자리에 네모가 보이기 때문이다. 날개의 흰색은 사이트 배경과 거의 같지만 진한 외곽선이 있어 형태가 유지된다. 시안용 사본은 [profile.svg](3-profile-image/profile.svg)다.
- 크기: 64px(사용자 승인). 원본의 칸 하나(24px)가 64px에서 정확히 3px이 되어 칸 폭이 고르다(128px이면 6px). 96px이면 칸이 4.5px이라 4px·5px 칸이 섞여 들쭉날쭉해진다. 처음에는 128px을 추천했고, 사용자 요청으로 시안에 64px을 더해 골랐다(2026-10-21).
- 대체 텍스트: 바로 옆에 활동명이 있으므로 꾸밈 이미지(`alt=""`)로 둔다. 화면 낭독기가 활동명을 두 번 읽지 않게 하기 위해서다.
- 사이트 안 위치: `src/assets/profile.svg`. 페이지에서 import해 `<img>`로 넣는다. `public/`에 두면 파일이 없어도 빌드가 통과하지만, import하면 파일이 없을 때 빌드가 실패하기 때문이다(글 이미지와 같은 이유, design.md 데이터 파일 형식). 인라인 SVG는 칸마다 `<rect>`가 있어(약 160개, 11KB) 두 언어 페이지 HTML에 매번 들어가므로 쓰지 않는다. `<img>`는 브라우저가 한 번 받아 두고 쓴다.

### 배치

- 하위 단계 1의 시안에서 사용자가 C안, 64px, 테두리 없음을 승인했다(2026-10-21).
- 넓은 화면(`sm` 이상): 소개 내용 전체(제목, 한 줄 소개, 이메일·링크) 오른쪽에 이미지를 둔다. 위쪽을 제목과 맞추고, 내용과의 간격은 `--spacing`의 6배다.
- 좁은 화면(`sm` 미만): 이미지를 제목 위로 올린다(왼쪽 정렬, 제목과의 간격은 같다).
- 크기 64px(칸 하나 3px), 테두리 없음.
- 고르지 않은 안: A안(활동명·한 줄 소개 왼쪽), B안(제목 위 단독), 크기 128px·96px, 점선 테두리. 시안은 [index.html](3-profile-image/index.html)에 그대로 둔다.

### 바뀌는 문서

이 변경이 끝나면 아래 문서의 해당 부분을 고치고, 고친 곳에서 이 문서로 링크한다(구현하는 하위 단계에서 고친다).

- design.md: 페이지 구성의 `/about/` 설명, 공통 UI(소개 페이지 모양), 필요하면 디렉터리 구조(이미지 위치)
- project_overview.md: 현재 상태에 이 변경을 한 줄 더한다.
