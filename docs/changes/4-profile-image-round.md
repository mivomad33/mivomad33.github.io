# 변경 4: 프로필 이미지를 원형 아이보리 배경으로

- 상태: 완료(2026-10-21). 하위 단계 1(시안)·2(구현)를 마친 뒤 변경 전체가 사용자 검토를 통과해 main에 squash merge했다.
- 브랜치: `change/profile-image-round`

## 배경

- [변경 3](3-profile-image.md)에서 소개 페이지에 프로필 이미지를 넣었다. 그때는 원본 SVG의 아이보리 배경(`#FCF6EC`)을 빼고 투명하게 썼다. 사이트 배경(`#fcfcfc`)과 색이 달라 이미지 자리에 네모가 보이기 때문이었다.
- 배포 뒤 사용자가 배경이 있는 원본을 쓰고, 정사각형 대신 원형으로 보여 주자고 했다(2026-10-21). 원형이면 배경색이 달라도 네모처럼 보이지 않고, 프로필 사진처럼 보인다.

## 요구사항

### 해야 하는 것

- 소개 페이지의 프로필 이미지를 원본 SVG(아이보리 배경 포함)로 바꾼다.
- 이미지를 원형으로 보여 준다.
- 테두리는 넣지 않는다(사용자 요청).

### 하지 않는 것

- 크기(64px)와 배치(넓은 화면에서 내용 오른쪽, 좁은 화면에서 제목 위)는 바꾸지 않는다(변경 3에서 승인한 그대로).
- 다른 곳(파비콘, OG 이미지 등)에는 넣지 않는다.

## 설계

- 이미지 파일: `src/assets/profile.svg`를 원본(배경 포함)으로 바꾼다. 시안용 사본은 [profile.svg](4-profile-image-round/profile.svg)다(비교용으로 지금 사이트의 투명 이미지도 [profile-transparent.svg](4-profile-image-round/profile-transparent.svg)로 두었다).
- 원형: 이미지 요소의 모서리를 둥글게 오려 낸다(`rounded-full`). 파일 자체는 정사각형 그대로다.
  - 캐릭터는 원 안에 모두 들어간다. 원본 512px 기준으로 가장 바깥인 날개 끝이 중심에서 약 224px(반지름 256px의 약 88%)이라 잘리지 않는다.
- 테두리 없음. 아이보리 원이 사이트 배경과 연하게 구분된다.
- 하위 단계 1의 시안을 사용자가 그대로(원형 아이보리, 64px, 테두리 없음) 승인했다(2026-10-21).
